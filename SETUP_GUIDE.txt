# ClimateIQ v5 — Complete Setup Guide

This guide explains how to set up ClimateIQ v5, prepare the SQLite database, build the Windows application, and run the project.

The setup only needs to be done once for the database and standalone application. After that, you can launch the application directly whenever you need it.

---

## 1. Convert the CSV Dataset to SQLite

This step is required when you are setting up the project for the first time or when you want to create a new database from a CSV dataset.

### Step 1.1 — Open Command Prompt

Press:

```text
Win + R
```

Type:

```text
cmd
```

and press **Enter**.

### Step 1.2 — Go to the Project Folder

Navigate to the ClimateIQ project directory.

For example:

```bat
cd C:\Users\lenovo\Documents\ClimateIQ_v5
```

If your project is located somewhere else, replace the path with the actual project location.

### Step 1.3 — Convert the CSV File

Run the CSV-to-SQLite conversion script:

```bat
python scripts\csv_to_sqlite.py "path_to_your_csv_file.csv"
```

For example:

```bat
python scripts\csv_to_sqlite.py "C:\Users\lenovo\Documents\ClimateIQ_v5\database\sample_tweets.csv"
```

If the conversion completes successfully, the database will be created at:

```text
database\climate_data.db
```

When you see a message indicating that the database is ready, this step is complete.

> **Note:** You normally only need to perform this conversion once. If you replace the CSV dataset with a new one and want to use it in ClimateIQ, run the conversion script again.

---

## 2. Build the Windows Application

ClimateIQ can be packaged as a standalone Windows application using PyInstaller.

There are two ways to build the application.

### Option A — Using BUILD.bat

This is the easiest method.

1. Open the `ClimateIQ_v5` project folder.
2. Locate `BUILD.bat`.
3. Double-click `BUILD.bat`.
4. Wait for PyInstaller to finish creating the application.

After a successful build, the standalone application will be available under:

```text
dist\ClimateIQ\
```

The main executable is:

```text
dist\ClimateIQ\ClimateIQ.exe
```

The database should also be available under:

```text
dist\ClimateIQ\database\climate_data.db
```

### Option B — Build from Command Prompt

Open Command Prompt and move to the project directory:

```bat
cd C:\Users\lenovo\Documents\ClimateIQ_v5
```

Then run:

```bat
python -m PyInstaller ClimateIQ.spec --noconfirm
```

PyInstaller will create the standalone application in the `dist` directory.

The resulting structure should include:

```text
dist\ClimateIQ\
├── ClimateIQ.exe
└── database\
    └── climate_data.db
```

---

## 3. Run ClimateIQ

There are two ways to run the application.

### Option A — Run from Python

This is useful during development or when making changes to the source code.

Open Command Prompt and run:

```bat
cd C:\Users\lenovo\Documents\ClimateIQ_v5
```

Then:

```bat
python main.py
```

The ClimateIQ desktop application should open.

### Option B — Run the Standalone Application

If you have already built the application, you do not need to run Python manually.

Open:

```text
dist\ClimateIQ\
```

and double-click:

```text
ClimateIQ.exe
```

This launches the standalone version of ClimateIQ.

---

## 4. Using the Application

Once ClimateIQ starts, the application connects to the local SQLite database and loads the available data.

A typical analysis workflow is:

1. Open ClimateIQ.
2. Select a **City** from the available options.
3. Select the required **Date Range**.
4. Click **Run Analysis**.
5. Review the sentiment statistics and generated charts.
6. Use **Export PDF** if you want to save the analysis as a report.
7. Use **Reset Dashboard** when you want to clear the current analysis and start another one.

The exact data and available results depend on the dataset currently stored in the database.

## 6. Common Errors and Solutions

### Error: `Database not found`

If ClimateIQ cannot find the database, first make sure that the database has been created.

Run:

```bat
python scripts\csv_to_sqlite.py "database\sample_tweets.csv"
```

Then check that this file exists:

```text
database\climate_data.db
```

For the standalone version, also check:

```text
dist\ClimateIQ\database\climate_data.db
```

---

### Error: Data Does Not Load in the Standalone Application

If the application opens but the data is not available, check the database location.

The standalone application should have:

```text
dist\ClimateIQ\
├── ClimateIQ.exe
└── database\
    └── climate_data.db
```

Make sure `climate_data.db` is actually present inside the `database` folder.

---

### Error: `'pyinstaller' is not recognized`

If Windows does not recognize the `pyinstaller` command, use the Python module form instead:

```bat
python -m PyInstaller ClimateIQ.spec --noconfirm
```

This is also the command used by the recommended build process.

If PyInstaller is not installed, install it with:

```bat
pip install pyinstaller
```

---

### Error: Python Is Not Recognized

If you receive an error indicating that `python` is not recognized, make sure Python 3.x is installed and added to the Windows PATH.

You can check the installation with:

```bat
python --version
```

If Python is installed correctly, this command should display the installed Python version.

pip install -r requirements.txt

python -m PyInstaller ClimateIQ.spec --noconfirm

After the build finishes, open:

```text
dist\ClimateIQ\ClimateIQ.exe
```

---

## 8. Development vs. Standalone Use

For development, testing, or modifying the source code, use:

```bat
python main.py
```

For normal use on a Windows machine where Python is not required, use:

```text
dist\ClimateIQ\ClimateIQ.exe
```

The standalone version is the recommended option when distributing ClimateIQ as a desktop application.

---

## 9. Before Distributing the Application

Before sharing the standalone ClimateIQ package with another user, check that the following are present:

```text
dist\ClimateIQ\
├── ClimateIQ.exe
└── database\
    └── climate_data.db
```

If the database is missing from the package, the application may open but will not be able to load the required dataset.

It is also a good idea to test the executable on the target Windows machine before distribution.
